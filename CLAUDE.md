## Model selection
- Default to Sonnet for routine work: known bugs, mechanical fixes, execution of an already-agreed plan, log/log-checking.
- Switch to Opus only for genuinely hard problems: cross-cutting refactors, architecture decisions, or debugging with no clear cause yet.
- For hard/architectural tasks, plan with Opus first, then switch to Sonnet to execute the agreed plan (or use /model opusplan, which does this automatically).
